# 解绑20台同屏布局

2026-10-08，实际项目 `D:\蓝牙模块优化`。

`APP/yuying_TFT.c` 的 `binding_device_list_page` 取消旧10台/页的时基轮显。读取实际绑定表，显示前20条记录，左右两列均分，20台时左1–10/右11–20。顶部保留14px“设备绑定”和“总设备数:N台”，底部“解绑”和“返回”与绑定页使用相同按钮矩形，保留原焦点编号与实际命令路径。

每台设备改为一行：序号、名称、完整12位十六进制MAC，正文11px、基线33起、行距11px；空表显示“--”。MAC按真实字宽右对齐，名称使用剩余宽度并留6px间隔，沿用既有字符边界裁剪，不改写设备名称。HEX字模不是等宽，D宽9px，最长MAC达108px，因此不使用假定固定72px的布局。最长MAC对应的名称可用宽度较小，这是保留20条同屏及完整MAC的空间取舍。

正常不同MAC设备受20通道容量限制，最多20台；异常Flash镜像可能恢复超过20条重复MAC记录，顶部仍显示真实总数，解绑页按本次“最多20台”需求展示前20条。解绑命令仍为主控发送0x04的一键解绑全部，本次没有改成单台选择解绑，也未修改绑定页、保存返回、BLE、协议或Flash。
