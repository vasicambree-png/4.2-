# CH584 二、三级页面 UI 适配

本轮参考 `D:/y/初锚力/初锚力_主页面和二级页面图片.zip`，在当前
`D:/蓝牙模块优化/CH584_V1_0_1` 工程的 384×168 屏幕上适配页面样式。
参考图和其中的说明仅作为视觉素材与示例数据，未将参考工程的功能移植到当前项目。

菜单采用白底图标侧栏、黑底内容区、大号标题、参数边框、底部按钮及反白选中项。
地址和其他设置页保留参考图的位置与灯泡装饰；八项菜单均使用当前项目的名称和回调。
“设备绑定”“信息汇总”没有替换为参考工程的“探头标定”“初锚力值”。
设备信号、电压、绑定名称仍为原有全屏双列，一屏显示 20 通道。

## 修改文件

- `CH584_V1_0_1/APP/yuying_TFT.c`：菜单专用绘图辅助函数和当前二、三级页面布局。
- `CH584_V1_0_1/APP/include/ui_menu_assets.h`：菜单用 16/18 像素字模和参考图静态图标。
- `tools/generate_menu_assets.py`：对应字模和图标生成器。
- `tools/ui_preview/`：为本轮菜单增加隔离输出、全部焦点及相关极值检查。

主页已有修改、菜单编号、`rank3_addr`/`re_flag` 分支、数据来源、数值换算、
名称/MAC 显示、轮显容量、上传地址特殊值、保存/解绑/恢复出厂/返回流程均保留。
未改串口协议、蓝牙扫描与绑定、Flash、驱动、定时器或页面状态写入逻辑。
原先未挂载的标定、密码、置零函数保留原样。

## 验证结果

本轮开始源码快照保留于 `tools/ui_preview/menu_output/yuying_TFT.session_before.c`。
`source_scope.json` 核对菜单绘制函数及新增字模 include/辅助函数之外的源码完全一致。

使用本机 MounRiver Studio 2 的 WCH GCC12，在 `CH584_V1_0_1/obj` 执行 `make main-build`。
当前 UI 重新编译、完整固件链接及 HEX 生成成功；构建没有输出警告或错误。
FLASH 316328/458752 字节（68.95%），RAM 65520/98304 字节（66.65%）。
固件为 `CH584_V1_0_1/obj/CH584M_TFT_HB.hex`。

桌面验证使用完整实际 UI 源码和 u8g2 字体、位图与几何算法，外设端点为空操作。
262 个用例检查初次、连续和独立绘制：无缺字、屏幕越界、数据改写、重绘差异或位图模式泄漏。
检查包含所有合法焦点、各三级分支、空/满绑定、轮显、最长名称、参数极值和上传特殊地址。
33 个主页、消息、保存/关机时基及重启提示用例前后逐像素一致。
目视核对普通页、三级页、全屏页和最大地址/亮屏时间，文字没有被参数框或按钮遮挡。
桌面 MSVC 编译会输出已有 SDK 头文件注释的编码警告；固件 WCH 编译未输出这些警告。

运行方式：

```powershell
python tools/ui_preview/run_preview.py --scope menus --output menu_output --baseline-sha256 dd2a849ce3d1c3df5e15f459bd154676ef8d67aec3b9182cec13bb2fa1d8143f
```

字模生成器沿用工程已使用的 Pillow 和本机微软雅黑粗体；在项目根目录执行
`python tools/generate_menu_assets.py`。静态图标来源只裁取图形，不包含示例数值。
本轮软件预览位于 `tools/ui_preview/menu_output/页面预览.html`，
四页总览为 `二三级页面预览.png`，各页原生和三倍图在 `after/`。
此输出目录保留本地并被 Git 忽略，历史首页预览 `output/` 没有覆盖。

烧录和实屏显示效果尚未验证。烧录当前 HEX 后，逐项进入八个菜单及相关三级页面，
检查黑白极性、字体清晰度、焦点移动、返回及动态数值刷新。
