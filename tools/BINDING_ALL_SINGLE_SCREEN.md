# 绑定设备全部同屏显示

## 行为

`APP/yuying_TFT.c` 的绑定设备子页直接读取 `g_binding_list` 和 `g_binding_count`。顶部显示“已绑定设备:N台”，每条名称前保留 `1:` 等序号，页面一次显示全部记录；没有页码、分页或轮显。扫描缓存中的名称即使被替换，也不会使已绑定设备从此页消失；扫描到但未成功绑定的候选设备不列入此页。

正常设备左右两列均衡排布：7台为左1–4/右5–7，10台为左1–5/右6–10，20台为左1–10/右11–20。正文11px，基线33起、行距11px；序号独立24px区域，名称147px，最长名称沿用现有裁剪函数，不改写绑定表。空表显示“--”。保留底部保存与返回及其焦点编号；二级残留re_flag=2也使用同屏列表。保存后回上级逻辑、Flash格式、协议及绑定规则未修改。

当前通道容量为20，正常新增设备每台至少占1路且不得与不同MAC冲突，因此正常独立设备最多20台，多路设备会减少可绑定台数。绑定表数组容量32；恢复入口允许同MAC占用已有通道，异常镜像可能含重复记录。绘图对超过20条记录采用四列、每列8行兜底以保留所有记录，名称区缩为64px。这不是增加实际通道容量，也不把异常32条测试数据当作正常硬件能力。
