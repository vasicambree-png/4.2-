# ST7306 4.2 寸屏幕：主页、二级菜单、三级页面适配

## 适配版本

仓库：`vasicambree-png/4.2-`

可烧录测试分支：`feat/st7306-42-ui-lowram`。此分支组合了：

- 已点亮的 ST7306 300×400 驱动（U8G2_R3 横屏）。
- **400×600 U8g2 虚拟坐标，对应物理 400×300**。虚拟纵向每 2 个 bit 映射到一个物理像素，文字位图采用双扫描行扩展。
- 原 `2.9-` 主界面、8 种菜单和各类三级页面的数据逻辑；重新编排几何坐标，未更改 STM32 串口页面指令。
- 3,000 B 分段帧缓冲（`SCREEN_ST7306_PAGE_BUFFER=1`）；10 次 picture-loop 完成整个画面的发送。20 KiB BLE 内存池及 96 KiB CH584M 链接脚本保持不变。

## 页面适配范围

| 页面 | 4.2 寸显示布局 | 状态/来源 |
|---|---|---|
| 主页第 1 页 | 2 列×5 行，通道 1–10；顶部电压/本机/分站/通讯 | 由 `UI_main.chu_num1=1` 选择 |
| 主页第 2 页 | 2 列×5 行，通道 11–20；顶部绑定数、已用通道和状态 | 由 `UI_main.chu_num1=2` 选择 |
| 二级菜单 | 左侧 8 项导航、右侧操作区；原本菜单索引/高亮逻辑不变 | `menu_rank=2` |
| 三级普通菜单 | 地址分区、组网测试、设备绑定、安装调试、上传设置、其他设置、信息汇总、返回主页 | `menu_rank=3` |
| 三级绑定详情 | 两列最多 20 台，超 20 时 4 列 8 行；解绑/保存/返回 | `UI_main.re_flag=1/2` |
| 三级组网结果 | 三组地址、次数/10、成功率、运行状态、返回 | 组网中/完成状态 |
| 三级 20 通道页 | 1–10 左列、11–20 右列；设备名、RSSI、设备电压；未到数据用 `--` | `re_flag=3/4/5` |
| 三级出厂确认 | 确认、返回，保留原选中索引 | `re_flag=6` |

为避免中文字库显示 `?`，目前使用已有字模中的「正在通信中」表述；原主页品牌位图保留。未改变设备类型、单位、数值转换、有效数据判断、绑定操作和通信协议。

## 下载和编译

Windows PowerShell：

```powershell
git clone -b feat/st7306-42-ui-lowram https://github.com/vasicambree-png/4.2-.git
```

或 GitHub 网页切换到 `feat/st7306-42-ui-lowram` 分支后下载 ZIP。

打开 `CH584_V1_0_1/CH584M_TFT_HB.wvproj`，核实 MCU 选择 **CH584M**，Clean → Build → 查看 `RAM` 和 `.map` 文件，再通过原 WCH 下载流程烧录。

## 如何验收

**接底板时：** 这份固件延续原启动保护。上电后先看到十字自检图；只有 STM32 下发有效的页面帧（`menu_rank=1/2/3`）时，屏幕才切到对应主页面/菜单。如果仅单独给屏幕板上电，仍然显示十字是预期的，不是 UI 未集成。

1. STM32 发送主页第 1 / 第 2 页，观察 1–10、11–20 通道类型/数据/单位是否完整且无重叠。
2. 切 `menu_rank=2`，滚动 8 项，验证左侧焦点；切 `menu_rank=3` 后验证右侧焦点不同时出现在左侧。
3. 分别进入地址、组网、绑定、安装、上传、其他、汇总、返回；重点测试设备名 20 条、RSSI、设备电压，以及对应的缺省 `--`。
4. 测试组网期间进度与结果高亮、绑定保存/解绑确认、出厂恢复确认。
5. 测试息屏/亮屏、BLE 扫描和 UART 连续刷新；注意 **分段缓冲需要重复 10 次渲染**，在真机上可能影响页面刷新速度。
